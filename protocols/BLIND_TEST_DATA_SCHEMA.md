# Blind Test Data Schema

## 1. Canonical Data Model

The local SQLite database is the authoritative source of truth. JSONL is an append-only audit export. Screen recordings and optional audio recordings are external artifacts: they may be linked to marker timestamps, but they do not control the state machine.

```text
Session
 ├── Participants
 ├── Rounds
 │    ├── Input event
 │    ├── Model run
 │    ├── Acoustic marker
 │    ├── Receiver response
 │    └── Metrics
 ├── State events
 └── External artifacts
```

All IDs are generated by the server. Recommended prefixes:

```text
s_000001   session       p_000001   participant
r_000001   round         e_000001   event
m_000001   marker        mr_000001  model run
a_000001   artifact
```

Every server event uses an ISO-8601 `created_at` timestamp. It may also include a process-relative `monotonic_ms` value. Browser timestamps are never authoritative.

## 2. Session

```json
{
  "session_id": "s_000001",
  "schema_version": "1.0",
  "status": "RECEIVER_RESPONSE",
  "current_round_index": 0,
  "max_rounds": 3,
  "version": 17,
  "active_marker_id": "m_000001",
  "created_at": "2026-10-01T15:00:00.000000+08:00",
  "updated_at": "2026-10-01T15:01:22.000000+08:00",
  "settled_at": null,
  "settings": {
    "confidence_alpha": 0.3,
    "require_both_to_continue": true,
    "audio_mode": "continuous_vcv",
    "recording_required": false
  }
}
```

Allowed session states:

```text
LOBBY, READY, INPUT_OPEN, MODEL_PROCESSING, SOUND_UPDATE,
RECEIVER_RESPONSE, ROUND_COMPLETE, NEXT_ROUND_PENDING,
SETTLEMENT, ERROR, ABORTED
```

`continuous_vcv` means that VCV remains active between markers. It does not mean that the server records audio.

## 3. Participant

```json
{
  "participant_id": "p_000001",
  "session_id": "s_000001",
  "label": "A",
  "client_token_hash": "sha256:...",
  "connected": true,
  "ready": true,
  "joined_at": "2026-10-01T15:00:04.000000+08:00",
  "last_seen_at": "2026-10-01T15:01:20.000000+08:00"
}
```

Store only a hash or server-side reference for the client token. Never store the raw token.

Roles are calculated per round:

```text
Round 1: A sender, B receiver
Round 2: B sender, A receiver
Round 3: A sender, B receiver
```

## 4. Round

One round is one sender-to-receiver exchange and has exactly one committed marker.

```json
{
  "round_id": "r_000001",
  "session_id": "s_000001",
  "round_index": 0,
  "sender_id": "p_000001",
  "receiver_id": "p_000002",
  "status": "RECEIVER_RESPONSE",
  "input_event_id": "e_000001",
  "model_run_id": "mr_000001",
  "marker_id": "m_000001",
  "receiver_response_id": null,
  "metrics_id": null,
  "created_at": "2026-10-01T15:00:30.000000+08:00",
  "completed_at": null
}
```

Allowed round states:

```text
OPEN, MODEL_PROCESSING, SOUND_UPDATED, RECEIVER_RESPONSE, COMPLETE, FAILED
```

## 5. Input Event

```json
{
  "event_id": "e_000001",
  "event_type": "SENDER_INPUT_ACCEPTED",
  "session_id": "s_000001",
  "round_id": "r_000001",
  "actor_id": "p_000001",
  "text": "My chest feels compressed and my breathing becomes shallow.",
  "text_hash": "sha256:...",
  "input_vadc": {
    "valence": 0.2,
    "arousal": 0.8,
    "dominance": 0.1,
    "confidence": 0.7
  },
  "client_submission_id": "participant_a-r1-submit-1",
  "created_at": "2026-10-01T15:00:30.000000+08:00",
  "monotonic_ms": 184223.421
}
```

The sender's text and self-assessment remain private until settlement.

## 6. VADC

```json
{
  "valence": 0.0,
  "arousal": 0.0,
  "dominance": 0.0,
  "confidence": 0.0
}
```

All four values must be finite numbers in `[0, 1]`. Their sources must remain distinct:

```text
input confidence       participant self-assessment
model confidence       model interpretation confidence
receiver confidence    receiver acoustic interpretation confidence
```

## 7. Model Run

```json
{
  "model_run_id": "mr_000001",
  "session_id": "s_000001",
  "round_id": "r_000001",
  "backend": "local_qwen",
  "model_name": "Qwen2.5-1.5B-LoRA",
  "prompt_version": "blind-v1",
  "input_event_id": "e_000001",
  "input_hash": "sha256:...",
  "output": {
    "valence": 0.18,
    "arousal": 0.84,
    "dominance": 0.12,
    "confidence": 0.61,
    "reasoning": "..."
  },
  "raw_output": "{...}",
  "status": "SUCCESS",
  "fallback_used": false,
  "fallback_reason": null,
  "latency_ms": 842,
  "created_at": "2026-10-01T15:00:31.000000+08:00"
}
```

Allowed model statuses:

```text
SUCCESS, TIMEOUT, INVALID_JSON, INVALID_RANGE, BACKEND_ERROR, FALLBACK
```

Fallbacks must be explicit and must never look like normal successful interpretations.

## 8. Acoustic Marker

The marker is the authoritative temporal object. It records that a valid sender input produced a new VCV acoustic state.

```json
{
  "marker_id": "m_000001",
  "session_id": "s_000001",
  "round_id": "r_000001",
  "sequence": 1,
  "event_id": "e_000002",
  "sender_id": "p_000001",
  "receiver_id": "p_000002",
  "model_run_id": "mr_000001",
  "input_event_id": "e_000001",
  "created_at": "2026-10-01T15:00:32.000000+08:00",
  "monotonic_ms": 186119.927,
  "input_hash": "sha256:...",
  "acoustic_state": {
    "vadc_source": "model_output",
    "voltages": {
      "timbre_v": 0.66,
      "frequency_v": 1.48,
      "amplitude_v": 8.38,
      "envelope_v": -3.60,
      "mode_v": -2.00,
      "chord_v": 5.00,
      "type_v": 0.00,
      "noise_v": 8.06
    },
    "progression": null
  },
  "osc_dispatch": {
    "host": "127.0.0.1",
    "port": 7001,
    "status": "SENT",
    "sent_at": "2026-10-01T15:00:32.010000+08:00"
  },
  "status": "COMMITTED"
}
```

Marker invariants:

1. `sequence` is strictly increasing within a session.
2. A completed round has exactly one committed marker.
3. Marker records are immutable.
4. Failed OSC dispatches cannot create committed markers.
5. A marker is not an audio-file boundary.
6. A marker can later be aligned with screen recording or optional audio.

## 9. Receiver Response

The receiver response references the existing marker and does not create a new marker.

```json
{
  "receiver_response_id": "rr_000001",
  "session_id": "s_000001",
  "round_id": "r_000001",
  "marker_id": "m_000001",
  "actor_id": "p_000002",
  "receiver_vadc": {
    "valence": 0.4,
    "arousal": 0.6,
    "dominance": 0.3,
    "confidence": 0.5
  },
  "somatic_shift": "The sound made my chest feel more open but less stable.",
  "listening_confirmed": true,
  "submitted_at": "2026-10-01T15:01:22.000000+08:00",
  "client_version": 18
}
```

`listening_confirmed` means that the receiver chose to respond. It does not mean that the sound ended.

## 10. Metrics

Metrics are calculated only after the receiver response is committed.

```json
{
  "metrics_id": "metrics_000001",
  "session_id": "s_000001",
  "round_id": "r_000001",
  "marker_id": "m_000001",
  "formula_version": "metrics-v1",
  "raw_distance": {
    "model": 0.021,
    "medium": 0.184,
    "total": 0.213
  },
  "confidence_adjusted_distance": {
    "model": 0.019,
    "medium": 0.156,
    "total": 0.187
  },
  "confidence": {
    "input": 0.7,
    "model": 0.61,
    "receiver": 0.5
  },
  "inter_round_drift": null,
  "created_at": "2026-10-01T15:01:22.100000+08:00"
}
```

Raw distances must be preserved even when the interface displays confidence-adjusted values. The first round has `inter_round_drift = null`.

## 11. State Event

State events are append-only and are never edited or deleted.

```json
{
  "state_event_id": "se_000001",
  "session_id": "s_000001",
  "round_id": "r_000001",
  "actor_id": "p_000001",
  "from_state": "INPUT_OPEN",
  "to_state": "MODEL_PROCESSING",
  "event_type": "SENDER_INPUT_SUBMITTED",
  "payload": {
    "input_event_id": "e_000001"
  },
  "created_at": "2026-10-01T15:00:30.000000+08:00",
  "monotonic_ms": 184223.421
}
```

Recovery is represented by a new event, not by rewriting the old event.

## 12. External Artifact

Screen recording is optional and external to the experiment state machine.

```json
{
  "artifact_id": "a_000001",
  "session_id": "s_000001",
  "artifact_type": "screen_recording",
  "path": "recordings/session_001.mov",
  "sha256": "sha256:...",
  "started_at": "2026-10-01T14:59:50.000000+08:00",
  "ended_at": "2026-10-01T15:05:42.000000+08:00",
  "status": "AVAILABLE",
  "required": false,
  "notes": "External recording; not required for state validity."
}
```

Optional audio recordings use the same artifact structure. They are never required for marker validity.

## 13. SQLite Reference Schema

```sql
CREATE TABLE sessions (
    session_id TEXT PRIMARY KEY,
    schema_version TEXT NOT NULL,
    status TEXT NOT NULL,
    current_round_index INTEGER NOT NULL DEFAULT 0,
    max_rounds INTEGER NOT NULL DEFAULT 3,
    version INTEGER NOT NULL DEFAULT 0,
    settings_json TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    settled_at TEXT
);

CREATE TABLE participants (
    participant_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    label TEXT NOT NULL CHECK (label IN ('A', 'B')),
    client_token_hash TEXT NOT NULL,
    connected INTEGER NOT NULL DEFAULT 1,
    ready INTEGER NOT NULL DEFAULT 0,
    joined_at TEXT NOT NULL,
    last_seen_at TEXT NOT NULL,
    UNIQUE(session_id, label)
);

CREATE TABLE rounds (
    round_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    round_index INTEGER NOT NULL,
    sender_id TEXT NOT NULL REFERENCES participants(participant_id),
    receiver_id TEXT NOT NULL REFERENCES participants(participant_id),
    status TEXT NOT NULL,
    input_event_id TEXT UNIQUE,
    model_run_id TEXT UNIQUE,
    marker_id TEXT UNIQUE,
    receiver_response_id TEXT UNIQUE,
    metrics_id TEXT UNIQUE,
    created_at TEXT NOT NULL,
    completed_at TEXT,
    UNIQUE(session_id, round_index)
);

CREATE TABLE input_events (
    event_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    round_id TEXT NOT NULL REFERENCES rounds(round_id),
    actor_id TEXT NOT NULL REFERENCES participants(participant_id),
    text TEXT NOT NULL,
    text_hash TEXT NOT NULL,
    input_vadc_json TEXT NOT NULL,
    client_submission_id TEXT NOT NULL,
    created_at TEXT NOT NULL,
    monotonic_ms REAL,
    UNIQUE(session_id, client_submission_id)
);

CREATE TABLE model_runs (
    model_run_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    round_id TEXT NOT NULL REFERENCES rounds(round_id),
    backend TEXT NOT NULL,
    model_name TEXT NOT NULL,
    prompt_version TEXT NOT NULL,
    input_event_id TEXT NOT NULL REFERENCES input_events(event_id),
    input_hash TEXT NOT NULL,
    output_json TEXT,
    raw_output TEXT,
    status TEXT NOT NULL,
    fallback_used INTEGER NOT NULL DEFAULT 0,
    fallback_reason TEXT,
    latency_ms INTEGER,
    created_at TEXT NOT NULL
);

CREATE TABLE markers (
    marker_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    round_id TEXT NOT NULL REFERENCES rounds(round_id),
    sequence INTEGER NOT NULL,
    event_id TEXT NOT NULL,
    sender_id TEXT NOT NULL REFERENCES participants(participant_id),
    receiver_id TEXT NOT NULL REFERENCES participants(participant_id),
    model_run_id TEXT NOT NULL REFERENCES model_runs(model_run_id),
    input_event_id TEXT NOT NULL REFERENCES input_events(event_id),
    acoustic_state_json TEXT NOT NULL,
    osc_dispatch_json TEXT NOT NULL,
    status TEXT NOT NULL,
    created_at TEXT NOT NULL,
    monotonic_ms REAL,
    UNIQUE(session_id, sequence),
    UNIQUE(session_id, round_id)
);

CREATE TABLE receiver_responses (
    receiver_response_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    round_id TEXT NOT NULL REFERENCES rounds(round_id),
    marker_id TEXT NOT NULL REFERENCES markers(marker_id),
    actor_id TEXT NOT NULL REFERENCES participants(participant_id),
    receiver_vadc_json TEXT NOT NULL,
    somatic_shift TEXT NOT NULL,
    listening_confirmed INTEGER NOT NULL,
    submitted_at TEXT NOT NULL,
    client_version INTEGER
);

CREATE TABLE metrics (
    metrics_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    round_id TEXT NOT NULL REFERENCES rounds(round_id),
    marker_id TEXT NOT NULL REFERENCES markers(marker_id),
    formula_version TEXT NOT NULL,
    raw_distance_json TEXT NOT NULL,
    confidence_adjusted_distance_json TEXT NOT NULL,
    confidence_json TEXT NOT NULL,
    inter_round_drift REAL,
    created_at TEXT NOT NULL
);

CREATE TABLE state_events (
    state_event_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    round_id TEXT REFERENCES rounds(round_id),
    actor_id TEXT REFERENCES participants(participant_id),
    from_state TEXT NOT NULL,
    to_state TEXT NOT NULL,
    event_type TEXT NOT NULL,
    payload_json TEXT NOT NULL,
    created_at TEXT NOT NULL,
    monotonic_ms REAL
);

CREATE TABLE artifacts (
    artifact_id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(session_id),
    artifact_type TEXT NOT NULL,
    path TEXT NOT NULL,
    sha256 TEXT,
    started_at TEXT,
    ended_at TEXT,
    status TEXT NOT NULL,
    required INTEGER NOT NULL DEFAULT 0,
    notes TEXT
);
```

## 14. Privacy Projections

Before settlement, the server returns role-specific projections.

### Sender may see

- session status;
- own input text and input VAD;
- current round number;
- acoustic update status.

### Receiver may see

- session status;
- current round number;
- listening status;
- response form;
- marker sequence number, if desired.

### Receiver must not see before settlement

- sender text;
- sender input VAD;
- model VAD;
- model reasoning;
- sender confidence.

After settlement, both participants may receive the complete dataset, subject to the project's privacy policy.

## 15. Export Shape

Canonical JSON export:

```json
{
  "schema_version": "1.0",
  "session": {},
  "participants": [],
  "rounds": [],
  "input_events": [],
  "model_runs": [],
  "markers": [],
  "receiver_responses": [],
  "metrics": [],
  "state_events": [],
  "artifacts": []
}
```

CSV is a presentation export only. One row represents one completed round:

```text
session_id,round_index,sender_label,receiver_label,marker_id,input_text,input_valence,input_arousal,input_dominance,input_confidence,model_valence,model_arousal,model_dominance,model_confidence,receiver_valence,receiver_arousal,receiver_dominance,receiver_confidence,model_distance,medium_distance,total_distance,marker_created_at
```

CSV must not be used to reconstruct the database.

## 16. Transaction Boundaries

Accepting sender input must commit atomically:

```text
validate request
→ create input event
→ create model run
→ validate acoustic output
→ send OSC
→ create marker
→ update round state
→ append state event
→ increment session version
```

Completing receiver response must commit atomically:

```text
validate response
→ create receiver response
→ calculate metrics
→ update round state
→ append state event
→ increment session version
```

## 17. Required Invariants

1. A session has at most two participants.
2. Every round has exactly one sender and one receiver.
3. Every completed round has exactly one committed marker.
4. Marker sequence numbers are strictly increasing.
5. Markers are immutable.
6. Receiver feedback always references the marker from the same round.
7. No frontend timer creates a marker.
8. A failed model or OSC call does not create a successful marker.
9. A new round cannot begin before the previous receiver response is complete.
10. Settlement never deletes or rewrites previous markers.
11. Screen-recording failure does not invalidate the server-side experiment log.
